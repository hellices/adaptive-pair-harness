# Adaptive AI Pair Harness

An open-source, VS Code-first AI pair-programming harness that helps developers
ship real products while understanding and owning the important code.

## Status

The project is in the design phase. No implementation has been scaffolded yet.

## Design

Read the approved
[product and system design](docs/superpowers/specs/2026-09-11-adaptive-ai-pair-harness-design.md).

The first implementation will focus on:

- a real-time inline pair loop in VS Code;
- incremental TypeScript and JavaScript analysis;
- tool-first, evidence-backed guidance;
- adaptive driver and navigator roles;
- user-owned GitHub memory;
- model routing and explicit token budgets;
- safe coexistence with other coding-agent harnesses.
